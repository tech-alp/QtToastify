# QtToastify Support

## Before Opening an Issue

1. Read the [documentation](README.md).
2. Search existing [GitHub issues](https://github.com/tech-alp/QtToastify/issues).
3. Reduce the problem to a minimal QML, C++, or CMake example.

## Choose the Right Channel

- Usage and integration questions: use the
  [support question template](https://github.com/tech-alp/QtToastify/issues/new?template=question.md).
- Reproducible defects: use the
  [bug report template](https://github.com/tech-alp/QtToastify/issues/new?template=bug_report.md).
- New behavior or API proposals: use the
  [feature request template](https://github.com/tech-alp/QtToastify/issues/new?template=feature_request.md).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and do not open a
  public issue.

Include QtToastify, Qt, CMake, compiler, operating system, and architecture
versions. Add the smallest relevant logs and screenshots. Public support is
best-effort; no response-time guarantee is provided.
