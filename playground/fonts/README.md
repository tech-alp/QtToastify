# Playground Fonts

Bu fontlar yalnız `QtToastifyPlayground` hedefi tarafından QML resource olarak
paketlenir ve `PlaygroundFonts.qml` içindeki `FontLoader` nesneleriyle yüklenir.
`Toastify` ve `ToastifyStyle` hedefleri font dosyası paketlemez veya yüklemez.
